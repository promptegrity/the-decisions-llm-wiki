# The Decisions LLM Wiki

A compounding knowledge base of **decision models**, organized by **decision job** — what you are trying to do:

| Job | Question |
|-----|----------|
| [Prioritize](models/prioritize/index.md) | What deserves attention and resources? |
| [Choose](models/choose/index.md) | How do I pick and commit? |
| [Create](models/create/index.md) | What options am I missing? |
| [Understand myself](models/understand-self/index.md) | What in me shapes this choice? |
| [Learn](models/learn/index.md) | What should I update next time? |
| [Relate](models/relate/index.md) | How do we understand each other? |
| [Collaborate](models/collaborate/index.md) | How do we work better as a team? |
| [Uncertainty](models/uncertainty/index.md) | What don’t we know? |
| [Systems](models/systems/index.md) | What larger dynamics am I in? |
| [Meta](models/meta/index.md) | How should deciding itself work? |

Built for **human + LLM** use: the agent should **apply** a model with you (multi-turn facilitation), not only explain it.

## Start here

1. [Decision jobs](index.md) — place the problem  
2. [Models hub](models/index.md) — pick a model  
3. Optional: [Routing](models/routing.md) · [Paths](models/paths/index.md) · [Comparisons](models/comparisons/index.md)  
4. [Schema for agents](AGENTS.md) — read-only Apply / Query  

## Layout

```
AGENTS.md              # read-only agent schema
index.md               # entry = Decision jobs map
models/                # DecisionModel pages by job family
  routing.md           # symptom → model
  paths/               # situation sequences
  comparisons/         # when to use which
  prioritize/ … meta/
```
