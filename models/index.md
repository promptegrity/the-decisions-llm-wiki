# Models

Hub for all decision models, grouped by **decision job**. Return to the [Decision jobs](/index.md) map if you need to re-locate the problem first.

## Locate aids

* [Routing table](routing.md) — symptom → job → primary model  
* [Situation paths](paths/index.md) — common situations as model sequences  
* [Comparisons](comparisons/index.md) — when to use which model  

## Families

* [Prioritize & Allocate](prioritize/index.md) — Scarce time and resources — decide what deserves focus, money, and effort. _(7 models)_
* [Choose & Commit](choose/index.md) — Options, dilemmas, and hard trade-offs — move from stuck to a decision you can own. _(10 models)_
* [Create Options](create/index.md) — When the real problem is a thin option set — invent and remix possibilities before choosing. _(2 models)_
* [Understand Myself](understand-self/index.md) — Motives, biases, energy, identity — see the decision-maker before the decision. _(10 models)_
* [Learn & Correct](learn/index.md) — Feedback, criticism, and wrong assumptions — improve the next decision, not only the last move. _(3 models)_
* [Relate & Negotiate](relate/index.md) — Other people as partners, opponents, or gifts — motives, conflict, trust, expectations. _(7 models)_
* [Collaborate & Lead](collaborate/index.md) — Groups that need to perform — composition, roles, stages, style, and stacked wins. _(5 models)_
* [Face Uncertainty](uncertainty/index.md) — Ignorance, rare shocks, opaque systems, layered failure — decide without false certainty. _(4 models)_
* [Read Systems](systems/index.md) — Markets, niches, and how ideas spread — patterns larger than one person or one team. _(2 models)_
* [Meta: How We Decide](meta/index.md) — The practice of deciding itself — tools, data, machines, and collective choice. _(1 model)_

## How to pick

1. Name the **job**, or open **routing** / a **path**.
2. Open that family hub (or follow the path).
3. Match the one-line intent to your situation.
4. **Apply** with the user — prefer `### Facilitation steps`, else `# How it works`, one step per turn.
