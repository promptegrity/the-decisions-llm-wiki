# Overview

The **Prisoner's Dilemma** is a game-theory archetype: two parties each choose **cooperate** or **defect**. Defecting looks safer or more profitable *individually*, yet **mutual defection** leaves both worse than **mutual cooperation**. Trust (or enforceable rules, reputation, repeated play) is what makes cooperation rational.

Core question: when trust is profitable — and when structure punishes it.

### Diagram

```text
                 Other cooperates    Other defects
  You cooperate |  reward, reward     |  sucker, tempt
  You defect    |  tempt, sucker     |  punish, punish
```

# When to use

- Partners, teams, or firms would gain from cooperation but fear being exploited.
- Price wars, arms races, or blame cycles look individually rational and collectively stupid.
- You design incentives, contracts, or cultures and need to see the trap.
- “If only they would trust us” is the refrain on both sides.

Skip it when the conflict is already interpersonal and needs interest-based craft (use [Conflict Resolution](/models/relate/conflict-resolution-model.md)) first, then return here for the incentive structure.

# How it works

Classic payoff sketch (numbers illustrative):

| | Other cooperates | Other defects |
|--|------------------|---------------|
| **You cooperate** | Reward for both (e.g. 3, 3) | You get sucker’s payoff (e.g. 0); other tempts (e.g. 5) |
| **You defect** | You tempt (e.g. 5); other gets 0 | Punishment for both (e.g. 1, 1) |

Individually, defect **dominates** if the game is one-shot and anonymous. Collectively, cooperate–cooperate is better than defect–defect.

### What changes the game

| Lever | Effect |
|-------|--------|
| **Repetition** | Future punishment/reward makes cooperation stable |
| **Reputation** | Defection becomes costly outside this round |
| **Transparency** | Harder to cheat unnoticed |
| **Enforcement** | Contracts, norms, third parties alter payoffs |
| **Shared identity** | Raises value of mutual reward |

### Questions

1. Is this **one-shot** or an ongoing relationship?
2. What does each side **fear** if they cooperate first?
3. Can we change **payoffs** (bonuses, penalties, guarantees) so cooperation wins?
4. What **signal** would make a cooperative move credible?

### How to act

1. **Lengthen the shadow of the future** — multi-round deals, visible relationships.
2. **Start with conditional cooperation** — tit-for-tat style: cooperate, answer defection, forgive.
3. **Reduce sucker’s payoff** — escrow, milestones, mutual hostages (fair ones).
4. **Name the dilemma** — once both see the trap, redesign becomes possible.

### Practice tip

When two teams dig in, draw the 2×2 live. Ask: “What rule or guarantee would make cooperate–cooperate the obvious cell?” If nobody can invent one, the structure — not the personalities — is the problem.

### Facilitation steps

1. **Players** — Who are the two (or more) sides, and is this one-shot or repeated?
2. **Payoffs** — Roughly: what does each get if both cooperate / both defect / mixed?
3. **Fear** — What does each side fear if they cooperate first?
4. **Levers** — Which lever can change the game (reputation, contract, transparency, length)?
5. **Move** — What cooperative or structural move will you try first?
