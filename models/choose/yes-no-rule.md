# Overview

The Yes/No Rule is a speed tool: set a simple criterion in advance, then answer **yes** or **no** without reopening the whole debate. It trades exhaustive analysis for a **precommitted filter** — useful when delay costs more than a slightly imperfect call.

The point is not impulsiveness. It is deciding *how* you will decide, then executing that rule when the moment comes.

### Diagram

```text
  Decision arrives → apply PRECOMMITTED rule → Yes / No
                         (no re-arguing case)
```

# When to use

- Decisions are frequent and similar (invites, small purchases, feature requests, “quick favors”).
- You stall on reversible choices and burn attention.
- You already know your priorities and need a gate, not a research project.
- Indecision is becoming its own cost (missed windows, backlog of open loops).

Skip it when the stakes are high and irreversible (use [SWOT Analysis](/models/prioritize/swot-analysis.md), [Rubber Band Model](/models/choose/rubber-band-model.md), or [Consequences Model](/models/choose/consequences-model.md)), when the goal is unclear (use [SMART Model](/models/prioritize/smart-model.md)), or when you are drowning in options (use [Jam Paradox](/models/choose/jam-paradox.md) first).

# How it works

### Build the rule before you need it

1. **Name the decision class** — e.g. “meeting invites,” “side projects under 5 hours,” “discounts under €50.”
2. **Write one primary criterion** — aligned with a real priority (energy, money, focus, values).
3. **Add a default** — if unclear after a short check → **No** (or Yes, if your bottleneck is under-commitment — choose consciously).
4. **Cap deliberation time** — e.g. 2 minutes or “sleep on it once,” then apply the rule.

### Example rules

| Domain | Rule |
|--------|------|
| Calendar | Yes only if it advances a top-3 goal *or* is a hard obligation; else No |
| Favors | Yes if under 30 minutes and no deadline conflict; else No / schedule later |
| Purchases | Yes if replaces a broken tool or was on a written list; else No for 48h |
| Opportunities | Yes if SMART-ready and portfolio has a free slot; else No / park |

### Steps in the moment

1. Identify which rule applies.
2. Check the criterion once (facts, not moods).
3. Say Yes or No — then **close the loop** (reply, archive, calendar).
4. Do not renegotiate unless new material facts appear.

### Practice tip

Default to **No** for requests that arrive as urgency from others; default to **Yes** only for pre-defined growth bets. Most people reverse that and wonder why their week disappears.

### Facilitation steps

1. **Domain** — For which kind of recurring decision do you need a default rule?
2. **Rule** — State a clear yes/no (or default) rule in one sentence before the next case.
3. **Exceptions** — When, if ever, may you override — and who decides?
4. **Apply** — Run the *current* decision through that rule only.
5. **Lock** — Will you write the rule where you will see it next time?
