# Overview

The Hard Choice Paradox sorts decisions by structure, not by drama. Many choices feel hard because we treat them like puzzles with one correct solution. In truth, some decisions are easy (one option dominates), some pit good against good, some pit bad against bad, and some are hard because the options are **on a par** — neither is better all-things-considered, and waiting for a secret ranking never ends.

Understanding the type frees you: stop searching for a phantom “right,” and start **creating reasons** to commit.

### Diagram

```text
  Type 1 Easy          one option dominates
  Type 2 Good vs good  real sacrifice either way
  Type 3 Bad vs bad    lesser harm
  Type 4 Hard / on a par  no single scale ranks them
```

# When to use

- You are stuck between options that both feel legitimate.
- Analysis has not produced a winner after reasonable effort.
- You fear regret more than you value either path.
- You want language for “this isn’t indecision — it’s a hard choice.”

Skip it when the real issue is cognitive bias distorting the options (use [Cognitive Distortion](/models/understand-self/cognitive-distortion.md)), or when you need a dilemma pull-apart of two specific poles (use [Rubber Band Model](/models/choose/rubber-band-model.md)).

# How it works

### Four types of decisions

| Type | Structure | What to do |
|------|-----------|------------|
| **1. Easy** | Clearly better vs worse | Choose the better; do not overthink |
| **2. Good vs good** | Two (or more) attractive goods | Values trade-off; you will sacrifice something real |
| **3. Bad vs bad** | Two costly harms | Damage control; pick the lesser harm deliberately |
| **4. Hard (on a par)** | Options not ranked by a single scale | Commit by *making* reasons; identity shapes the choice |

The paradox: we apply easy-decision methods (more data, more pros/cons) to type 4, expecting a hidden ranking. Extra data often will not help. What helps is authorship — who you will have become by choosing.

### Questions to classify

1. If a wise friend saw only the facts, would one option obviously win? → likely easy.
2. Am I giving up a real good either way? → good vs good.
3. Am I only limiting damage? → bad vs bad.
4. Do both options fit different selves I could honestly be? → hard / on a par.

### Practice tip

Name the type out loud before more research. For type 4, write: “I choose A because I am becoming the kind of person who…” Then stop collecting arguments for the unchosen path (see also [Cognitive Dissonance Theory](/models/understand-self/cognitive-dissonance.md) after you commit).

### Facilitation steps

1. **Options** — What options are you stuck between?
2. **Type** — Classify: easy / good-vs-good / bad-vs-bad / hard (on a par). Why?
3. **Stop fake search** — If hard/on a par: what extra data will *not* create a ranking?
4. **Author** — Complete: “I choose ___ because I am becoming the kind of person who…”
5. **Close** — What will you stop collecting arguments for the unchosen path?
