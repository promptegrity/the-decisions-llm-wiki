# Situation

You must move without false certainty: new domain, unclear risk surface, opaque vendor/system, or a shock that broke the old map. The job is not only to *name* ignorance — it is to **act anyway** with legible rules.

# Job placement

Primary: **uncertainty**. Secondary: **choose** (timing, defaults, abandon signals). Use **learn** if a failure already happened.

# Path (ordered)

1. **[Rumsfeld Matrix](/models/uncertainty/rumsfeld-matrix.md)** — sort known knowns, known unknowns, and hunt unknown unknowns carefully.  
2. **[Black Box Model](/models/uncertainty/black-box-model.md)** — for subsystems you will not open: govern via inputs/outputs, trust limits, contracts.  
3. **[Consequences Model](/models/choose/consequences-model.md)** or **[Stop Rule](/models/choose/stop-rule.md)** — lock early direction and/or pre-commit signals that mean “change course.”  
4. Optional: **[Black Swan Theory](/models/uncertainty/black-swan-theory.md)** if the framing is a rare high-impact break with inductive comfort.

# Alternate forks

- **Rare shock already hit; plans are scrap** — Black Swan → Consequences / Stop Rule (skip full Rumsfeld if the map was rewritten).  
- **Ops / safety failure, layered defenses** — [Swiss Cheese](/models/uncertainty/swiss-cheese-model.md) then path [Learn from failure](/models/paths/learn-from-failure.md).  
- **Vendor, AI, or opaque process with a counterpart** — Black Box → [Expectation Management](/models/relate/expectation-management-model.md).  
- **Post-mortem on a miss** — path [Learn from failure](/models/paths/learn-from-failure.md) first.  
- **Need more options before acting** — path [Blank page / need options](/models/paths/blank-page-need-options.md).

# Done when

A knowledge map exists (at least known vs unknown that matter), one opaque zone has a governance rule if relevant, and **one** action rule or stop rule is written for this week — not only a list of uncertainties.
