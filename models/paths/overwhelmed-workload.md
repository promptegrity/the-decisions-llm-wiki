# Situation

You (or your team) are submerged: long lists, reactive days, important work slipping, guilt about saying no.

# Job placement

Primary: **prioritize**. Secondary: **choose** (Stop Rule / Yes-No for commitments).

# Path (ordered)

1. **[SMART](/models/prioritize/smart-model.md)** — only if the *goal* is foggy. Skip if goals are clear.  
2. **[Eisenhower Matrix](/models/prioritize/eisenhower-matrix.md)** — sort the live task load.  
3. **[Pareto Principle](/models/prioritize/pareto-principle.md)** — if still too many “important” items, find the vital few.  
4. **[Project Portfolio](/models/prioritize/project-portfolio.md)** — if multi-project, not just tasks.  
5. **[Stop Rule](/models/choose/stop-rule.md)** or **[Yes/No Rule](/models/choose/yes-no-rule.md)** — protect the new load with defaults and exit rules.

# Alternate forks

- Scope/time/money fight on one delivery → [PM Triangle](/models/prioritize/project-management-triangle.md).  
- Values dilemma about *why* you are overloaded → [Rubber Band](/models/choose/rubber-band-model.md).

# Done when

A reduced Do list exists, Schedule time is blocked, and at least one Eliminate/Delegate or project pause is real.
