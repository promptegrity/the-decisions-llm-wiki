# Situation

You (or the team) default to one idea, feel stuck on a blank page, or know the real problem is a **thin option set** — not choosing among many good alternatives.

# Job placement

Primary: **create**. Move to **choose** once options exist (and optionally **systems** if the bet is about markets/spread).

# Path (ordered)

1. **[Thinking Outside the Box](/models/create/thinking-outside-the-box.md)** — name the invisible frame and what “counts” as a valid option.  
2. **[Morphological Box and SCAMPER](/models/create/morphological-box-scamper.md)** — generate and remix options systematically.  
3. **[Niche Model](/models/choose/niche-model.md)** — stress-test where strength meets a real gap (optional if the next step is pure shortlist choice).  
4. Optional handoff: **[Jam Paradox](/models/choose/jam-paradox.md)** or path **[Cannot choose](/models/paths/cannot-choose.md)** once a shortlist exists.

# Alternate forks

- **Already too many options** — do **not** create more; use [Jam Paradox](/models/choose/jam-paradox.md) then Purchase Decision or Rubber Band on a shortlist.  
- **Go-to-market / where to play** (offer exists; market position unclear) → path [Go-to-market](/models/paths/go-to-market-where-to-play.md).  
- **Indecision on two poles** after options exist → [Rubber Band](/models/choose/rubber-band-model.md) or path [Cannot choose](/models/paths/cannot-choose.md).  
- **Strategic option already named** — stress-test with [SWOT](/models/prioritize/swot-analysis.md) instead of more ideation.

# Done when

At least **three distinct options** are named, the old frame is explicit, and either one option is ready for a small experiment or a shortlist is ready for a choose model.
