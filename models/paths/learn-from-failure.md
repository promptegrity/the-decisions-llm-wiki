# Situation

A miss, post-mortem, harsh review, or repeated class of mistake. You need learning, not only blame or a new tactic.

# Job placement

Primary: **learn**. Add **uncertainty** if defenses/systems failed.

# Path (ordered)

1. **[Feedback Analysis](/models/learn/feedback-analysis.md)** — prediction vs outcome (write both).  
2. **[Critique Model](/models/learn/critique-model.md)** — if external feedback is loud, filter signal.  
3. **[Double-Loop Learning](/models/learn/double-loop-learning.md)** — what governing assumption failed?  
4. Optional ops failure → **[Swiss Cheese](/models/uncertainty/swiss-cheese-model.md)**.  
5. Optional rare shock framing → **[Black Swan](/models/uncertainty/black-swan-theory.md)**.

# Alternate forks

- Team delivery miss → also [Team stuck](team-stuck.md).  
- Personal thinking trap → [Cognitive Distortion](/models/understand-self/cognitive-distortion.md) before rewriting the story.

# Done when

One updated rule or assumption is written, and one next-action experiment is scheduled.
