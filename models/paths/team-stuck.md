# Situation

A team under-delivers, fights, or feels “stuck”: new group, reorg, storming, or plateau after a good start.

# Job placement

Primary: **collaborate**. Use **relate** for dyadic conflict or trust traps.

# Path (ordered)

1. **[Team Performance Model](/models/collaborate/team-performance-model.md)** — diagnose stage (forming→performing).  
2. **[Team Model](/models/collaborate/team-model.md)** — skills, motivation, chemistry if viability is in doubt.  
3. **[Roles Model](/models/collaborate/roles-model.md)** — coverage gaps and role clashes.  
4. **[Management Styles](/models/collaborate/management-styles.md)** — match leadership style to stage/maturity.  
5. **[Result Optimization](/models/collaborate/result-optimization-model.md)** — stack early visible wins if morale/delivery need fuel.

# Alternate forks

- Two parties in conflict → [Conflict Resolution](/models/relate/conflict-resolution-model.md).  
- Cooperate/defect incentives → [Prisoner's Dilemma](/models/relate/prisoners-dilemma.md).  
- Delivery triangle politics → [PM Triangle](/models/prioritize/project-management-triangle.md).

# Done when

Stage is named aloud, one structural fix (role, membership, or style) is chosen, and a near-term win is scheduled.
