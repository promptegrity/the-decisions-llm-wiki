# Situation

An idea, product, or offer already exists (or is close). The stuck point is **where to play**: who adopts, hits vs niches, and which segment deserves the next bet — not inventing from a blank page.

# Job placement

Primary: **systems**. Secondary: **choose** (Niche and commitment). Use **create** only if the offer/options are still missing.

# Path (ordered)

1. **[Diffusion Model](/models/systems/diffusion-model.md)** — map adopter groups and why spread stalls (chasm, attributes).  
2. **[Long Tail Model](/models/systems/long-tail-model.md)** — hits vs niches; where value sits in the distribution.  
3. **[Niche Model](/models/choose/niche-model.md)** — place a bet where strength meets a gap others leave open.  
4. Optional: **[SWOT Analysis](/models/prioritize/swot-analysis.md)** if several strategic positions compete for the same resources.

# Alternate forks

- **No real offer / zero options** — path [Blank page / need options](/models/paths/blank-page-need-options.md) first.  
- **Personal career niche, not market** — [Niche Model](/models/choose/niche-model.md) or path [Career or role fit](/models/paths/career-role-fit.md); skip Diffusion/Long Tail if not market-shaped.  
- **Social milieus / taste first** — [Bourdieu and Sinus-Milieus](/models/relate/bourdieu-sinus-milieus.md) before Diffusion.  
- **Too many market ideas** — [Jam Paradox](/models/choose/jam-paradox.md) on positions, then Niche.  
- **Indecision on two market poles** — path [Cannot choose](/models/paths/cannot-choose.md).

# Done when

Adopter stage (or target group) is named, hit-vs-niche position is explicit, and one **segment bet** or next experiment is written.
