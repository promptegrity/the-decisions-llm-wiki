# Situation

Indecision that lasts: two (or more) options feel legitimate; research does not end; fear of regret dominates.

# Job placement

Primary: **choose**. Check **understand-self** if bias or identity fog is central.

# Path (ordered)

1. **[Hard Choice Paradox](/models/choose/hard-choice-paradox.md)** — classify the decision type.  
2. **[Rubber Band Model](/models/choose/rubber-band-model.md)** — if two poles: map pulls and holds.  
3. **[Crossroads](/models/choose/crossroads.md)** — if it is a life junction after classification.  
4. **[Yes/No Rule](/models/choose/yes-no-rule.md)** — lock a default once the type is clear.  
5. Optional: **[Jam Paradox](/models/choose/jam-paradox.md)** first if the real problem is *too many* options.

# Alternate forks

- Thinking traps (catastrophizing, all-or-nothing) → [Cognitive Distortion](/models/understand-self/cognitive-distortion.md) before step 1.  
- Complex multi-criteria buy → [Purchase Decision Model](/models/choose/purchase-decision-model.md).  
- Waiting is the strategy → [Consequences Model](/models/choose/consequences-model.md).

# Done when

The type is named, a commitment sentence exists, and argument-collecting for the unchosen path has a stop.
