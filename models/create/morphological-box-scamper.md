# Overview

Creative breakthroughs rarely come from waiting for inspiration. **Morphological Box** and **SCAMPER** give structure so you can invent on purpose: first decompose the problem into parameters and combinations (Morphological Box), then deliberately twist existing ideas (SCAMPER).

Together they answer: *How do I get more and better options without relying on luck?*

### Diagram

```text
  Dim A: a1 | a2 | a3
  Dim B: b1 | b2 | b3     → pick cells → combine → SCAMPER remix
  Dim C: c1 | c2 | c3
```

# When to use

- Brainstorming feels stuck, repetitive, or dominated by the loudest idea.
- You need many variants of a product, process, story, or solution — not one “clever” guess.
- The problem has clear parts (features, steps, materials, audiences) that can be recombined.
- You want creativity that is auditable: others can see how an idea was generated.

Skip it when you already have too many options and need to cut (use [Jam Paradox](/models/choose/jam-paradox.md) thinking) or when the issue is prioritization of known work (use [Eisenhower Matrix](/models/prioritize/eisenhower-matrix.md)).

# How it works

## Morphological Box (Zwicky-style)

1. **Define the challenge** in one sentence (e.g. “design a better lunch break,” “improve onboarding”).
2. **List parameters** — independent dimensions of the solution (who, where, medium, cost, duration, tone…).
3. **List values** for each parameter (concrete alternatives, not vague labels).
4. **Combine** — pick one value per parameter to form a full concept; repeat across unlikely pairings.
5. **Filter** — keep combinations that are feasible *and* interesting; discard noise.

Example sketch:

| Parameter | Options |
|-----------|---------|
| Audience | self / team / clients |
| Format | checklist / ritual / tool |
| Frequency | daily / weekly / on demand |

A “weekly ritual for the team” is one cell in the box — structured, not random.

## SCAMPER (remix checklist)

Take an existing idea or object and ask:

| Letter | Prompt |
|--------|--------|
| **S**ubstitute | What can I replace (material, step, role, channel)? |
| **C**ombine | What can I merge with something else? |
| **A**dapt | What else is like this — what can I borrow? |
| **M**odify / Magnify | What if I change scale, emphasis, or intensity? |
| **P**ut to other uses | Who else could use this, or for what else? |
| **E**liminate | What can I remove to make it stronger? |
| **R**everse / Rearrange | What if I flip order, roles, or assumptions? |

### Practice tip

Run Morphological Box for *breadth*, then SCAMPER on the best 2–3 combinations for *surprise*. Structure first; wildness second — that is the point of the pairing.

### Facilitation steps

1. **Problem** — What are we generating options *for*? State it in one sentence.
2. **Parameters** — List the dimensions/parts of the solution space (the morphological axes).
3. **Values** — For each dimension, list possible values without judging yet.
4. **Combine** — Pick 2–3 combinations that look new or useful.
5. **SCAMPER** — On the best combination (or on a stuck idea): Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse — which lever opens something?
6. **Shortlist** — Which 1–2 options deserve a real test next?
