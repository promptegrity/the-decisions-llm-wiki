# Overview

Feedback Analysis trains self-evaluation by writing down what you **expect** from a decision or piece of work, then later comparing that prediction with what **actually happened**. You learn where your judgment is sharp and where it systematically lies — not from vibes after the fact, but from a written trail.

Popularized in knowledge-work practice (often associated with Peter Drucker): the feedback you need most is the gap between intention and result.

### Diagram

```text
  predict → act → observe outcome → compare → update rule
```

# When to use

- You finish work but cannot tell if it was “good” without others’ applause.
- You keep repeating the same planning mistakes (overconfidence, underestimating time, wrong audience).
- You want a personal learning loop for decisions, not only for deliverables.
- Reviews feel vague (“that went okay”) and never change behavior.

Skip it when you need immediate external critique on tone or craft (use [Critique Model](/models/learn/critique-model.md)), when the goal itself is still fuzzy (use [SMART Model](/models/prioritize/smart-model.md)), or when you need a fast go/no-go (use [Yes/No Rule](/models/choose/yes-no-rule.md)).

# How it works

### The loop

1. **Before** — write a short prediction: what success looks like, by when, what you will do, and what you might get wrong.
2. **Do the work / make the decision** — do not edit the prediction to look smarter later.
3. **After** (days to months later) — compare outcome to prediction in writing.
4. **Extract one pattern** — e.g. “I underprice time by ~2×,” “I overestimate how clear my writing is,” “I underrate quiet stakeholders.”
5. **Adjust the next prediction** — change process, not just self-talk.

### What to record (keep it tiny)

| Field | Example |
|-------|---------|
| Decision / work | Launch side-project landing page |
| Expected result | 50 signups in 2 weeks |
| Expected cost | 8 hours |
| Actual result | 12 signups |
| Actual cost | 20 hours |
| Lesson | Copy was vague; time for design always doubles |

### Practice tip

Schedule the “after” date when you write the “before.” Without a calendar reminder, Feedback Analysis becomes wishful journaling. One honest comparison beats ten unread notes.

### Facilitation steps

1. **Prediction** — What did you expect to happen (write it as if before the outcome)?
2. **Outcome** — What actually happened?
3. **Gap** — Where did expectation and reality diverge?
4. **Cause** — What did you misread (facts, model, luck, execution)?
5. **Update** — What rule or habit changes for the next similar decision?
