# Routing table

Quick Locate aid: symptom → **job** → primary model (and one alternative). Return to the [Decision jobs](/index.md) map or the [models hub](/models/index.md).

**How to use**

- Prefer a [situation path](/models/paths/index.md) when the user needs a **sequence**, not a single entry model.
- Use this table when one **entry model** is enough to start; follow `# Relations` or a path for the next step.
- Multi-step situations already curated: [paths index](/models/paths/index.md) (workload, cannot choose, team, relate, career, failure, blank page, ignorance, go-to-market).
