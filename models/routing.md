# Routing table

Quick Locate aid: symptom → **job** → primary model (and one alternative). Return to the [Decision jobs](/index.md) map or the [models hub](/models/index.md).

Prefer a [situation path](/models/paths/index.md) when the user needs a **sequence**, not a single entry model.

| Symptom (examples) | Job | Primary | Alternative | Avoid if |
|--------------------|-----|---------|-------------|----------|
| To-do list on fire; everything feels urgent | prioritize | [Eisenhower Matrix](/models/prioritize/eisenhower-matrix.md) | [Pareto Principle](/models/prioritize/pareto-principle.md) | Goal itself is unclear → SMART first |
| Goal is foggy (“get better,” “grow”) | prioritize | [SMART Model](/models/prioritize/smart-model.md) | [Project Portfolio](/models/prioritize/project-portfolio.md) | Choosing among clear options → SWOT / Yes-No |
| Too many projects; nothing has overview | prioritize | [Project Portfolio](/models/prioritize/project-portfolio.md) | [BCG Matrix](/models/prioritize/bcg-matrix.md) | Single task list only → Eisenhower |
| Need to focus effort where it pays | prioritize | [Pareto Principle](/models/prioritize/pareto-principle.md) | [Eisenhower Matrix](/models/prioritize/eisenhower-matrix.md) | Strategic option design → SWOT |
| Scope / time / budget fight | prioritize | [Project Management Triangle](/models/prioritize/project-management-triangle.md) | [Project Portfolio](/models/prioritize/project-portfolio.md) | Personal task triage → Eisenhower |
| Stress-test a strategic option | prioritize | [SWOT Analysis](/models/prioritize/swot-analysis.md) | [BCG Matrix](/models/prioritize/bcg-matrix.md) | Values dilemma → Rubber Band |
| Stuck between two pulls | choose | [Rubber Band Model](/models/choose/rubber-band-model.md) | [Hard Choice Paradox](/models/choose/hard-choice-paradox.md) | Low-stakes speed → Yes/No Rule |
| Hard life choice; no “right” answer appears | choose | [Hard Choice Paradox](/models/choose/hard-choice-paradox.md) | [Crossroads](/models/choose/crossroads.md) | Cognitive bias is the real issue → Cognitive Distortion |
| Need a fast default | choose | [Yes/No Rule](/models/choose/yes-no-rule.md) | [Stop Rule](/models/choose/stop-rule.md) | Deep values conflict → Rubber Band |
| Paralyzed by too many options | choose | [Jam Paradox](/models/choose/jam-paradox.md) | [Purchase Decision Model](/models/choose/purchase-decision-model.md) | Only two poles → Rubber Band |
| Complex buy / multi-criteria choice | choose | [Purchase Decision Model](/models/choose/purchase-decision-model.md) | [SWOT Analysis](/models/prioritize/swot-analysis.md) | Simple yes/no → Yes/No Rule |
| Waiting is killing options | choose | [Consequences Model](/models/choose/consequences-model.md) | [Stop Rule](/models/choose/stop-rule.md) | Already committed → Stop Rule |
| When to abandon a plan | choose | [Stop Rule](/models/choose/stop-rule.md) | [Feedback Analysis](/models/learn/feedback-analysis.md) | Never decided → Consequences / Yes-No |
| Need more options first | create | [Morphological Box and SCAMPER](/models/create/morphological-box-scamper.md) | [Thinking Outside the Box](/models/create/thinking-outside-the-box.md) | Already too many options → Jam Paradox |
| Learn from prediction vs outcome | learn | [Feedback Analysis](/models/learn/feedback-analysis.md) | [Double-Loop Learning](/models/learn/double-loop-learning.md) | Receiving critique live → Critique Model |
| Conflict with someone | relate | [Conflict Resolution Model](/models/relate/conflict-resolution-model.md) | [Appreciative Inquiry](/models/relate/appreciative-inquiry.md) | Incentive trap → Prisoner's Dilemma |
| Trust / cooperate vs defect | relate | [Prisoner's Dilemma](/models/relate/prisoners-dilemma.md) | [Expectation Management](/models/relate/expectation-management-model.md) | Pure interpersonal repair first → Conflict Resolution |
| Team is new or storming | collaborate | [Team Performance Model](/models/collaborate/team-performance-model.md) | [Team Model](/models/collaborate/team-model.md) | Role gaps only → Roles Model |
| Unknown risks / unknown unknowns | uncertainty | [Rumsfeld Matrix](/models/uncertainty/rumsfeld-matrix.md) | [Black Box Model](/models/uncertainty/black-box-model.md) | Rare extreme event framing → Black Swan |
| Rare high-impact shock | uncertainty | [Black Swan Theory](/models/uncertainty/black-swan-theory.md) | [Swiss Cheese Model](/models/uncertainty/swiss-cheese-model.md) | Routine process failure → Swiss Cheese |
| How ideas or products spread | systems | [Diffusion Model](/models/systems/diffusion-model.md) | [Long Tail Model](/models/systems/long-tail-model.md) | Personal niche bet → Niche Model |
| Role feels wrong / career fork | understand-self | [Personal Performance](/models/understand-self/personal-performance-model.md) | [Flow State](/models/understand-self/flow-state.md) | Path: [Career or role fit](/models/paths/career-role-fit.md) |
| Missed call / post-mortem | learn | [Feedback Analysis](/models/learn/feedback-analysis.md) | [Double-Loop Learning](/models/learn/double-loop-learning.md) | Path: [Learn from failure](/models/paths/learn-from-failure.md) |
| Need more options (blank page) | create | [Morphological Box / SCAMPER](/models/create/morphological-box-scamper.md) | [Thinking Outside the Box](/models/create/thinking-outside-the-box.md) | Already too many → Jam Paradox |
| Life balance across dimensions | understand-self | [Uffe Elbæk Radar](/models/understand-self/uffe-elbaek-radar.md) | [Past–Present–Future](/models/understand-self/past-present-future.md) | Single task fire → Eisenhower |
