# Overview

Sometimes you lack **ideas**; sometimes you misread **how ideas spread** or where **value sits** in a market.

# When to use which

| Need | Use |
|------|-----|
| Systematically invent alternatives | [Morphological Box / SCAMPER](/models/create/morphological-box-scamper.md) |
| Notice and leave the invisible frame | [Thinking Outside the Box](/models/create/thinking-outside-the-box.md) |
| Bet where strength meets a gap | [Niche Model](/models/choose/niche-model.md) |
| Hits vs niches in distribution | [Long Tail](/models/systems/long-tail-model.md) |
| How an innovation crosses adopter groups | [Diffusion Model](/models/systems/diffusion-model.md) |
| Too many options already | [Jam Paradox](/models/choose/jam-paradox.md) — do **not** create more first |

# Suggested sequences

1. **Blank page** → Outside the Box (name frame) → Morphological/SCAMPER → Niche stress-test.  
2. **Go-to-market** → Diffusion → Long Tail (where to play) → Niche.  
3. **Overwhelmed by ideas** → Jam Paradox → Purchase Decision or Rubber Band on shortlist.
