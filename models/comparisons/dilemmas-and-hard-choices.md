# Overview

“I can’t decide” covers different structures. Matching the **structure of difficulty** beats more pros/cons.

# When to use which

| Structure | Use | Signal |
|-----------|-----|--------|
| Two poles pulling you | [Rubber Band](/models/choose/rubber-band-model.md) | Pull vs hold; values tension |
| Options may be “on a par” / no hidden ranking | [Hard Choice Paradox](/models/choose/hard-choice-paradox.md) | Analysis never yields a winner |
| Life junction; need to see paths | [Crossroads](/models/choose/crossroads.md) | “And now?” moment after classifying |
| Too many options → paralysis | [Jam Paradox](/models/choose/jam-paradox.md) | Long list, shallow compare |
| Recurring low/medium stakes | [Yes/No Rule](/models/choose/yes-no-rule.md) | Need a default, not a philosophy |
| Multi-criteria purchase-like choice | [Purchase Decision](/models/choose/purchase-decision-model.md) | Weights and scores help |
| Timing / option decay | [Consequences](/models/choose/consequences-model.md) | Waiting shrinks the tree |
| When to abandon a commitment | [Stop Rule](/models/choose/stop-rule.md) | Pre-commit exit signals |

# Suggested sequences

1. **Stuck forever** → Hard Choice (type) → Rubber Band if two poles → Yes/No once type is clear.  
2. **Too many tabs open** → Jam Paradox → Purchase Decision or Rubber Band on the shortlist.  
3. **Life turn** → Hard Choice → Crossroads → Stop Rule for the path you leave.  
4. **Bias suspected** → [Cognitive Distortion](/models/understand-self/cognitive-distortion.md) *before* Hard Choice.
