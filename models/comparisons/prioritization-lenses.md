# Overview

Several models help when **attention or resources are scarce**. They are not interchangeable: some clarify the *goal*, some sort *tasks*, some reallocate across *projects*, some force *trade-offs*.

# When to use which

| If you need… | Use | Not when… |
|--------------|-----|-----------|
| Goal clarity before any prioritization | [SMART](/models/prioritize/smart-model.md) | Options are already clear and you only need a pick |
| Daily/weekly task triage (urgent vs important) | [Eisenhower](/models/prioritize/eisenhower-matrix.md) | Many parallel initiatives need portfolio view |
| Find the vital few drivers of an outcome | [Pareto](/models/prioritize/pareto-principle.md) | You need ethical/values choice, not concentration |
| See all initiatives and capacity | [Project Portfolio](/models/prioritize/project-portfolio.md) | Single list of small tasks |
| Invest vs drop across efforts | [BCG Matrix](/models/prioritize/bcg-matrix.md) | Pure scheduling of one week’s tasks |
| Negotiate scope / time / cost | [PM Triangle](/models/prioritize/project-management-triangle.md) | Personal values dilemma |

# Suggested sequences

1. **Foggy ambition** → SMART → Eisenhower (or Portfolio if multi-project).  
2. **Overloaded operator** → Eisenhower → Pareto on what remains.  
3. **Org / product pressure** → PM Triangle → Portfolio → BCG if killing initiatives.  
4. **Compare strategic options** → SWOT (same family) then Portfolio to fund the winner.
