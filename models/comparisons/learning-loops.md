# Overview

Improving decisions after the fact needs different tools: **prediction vs outcome**, **receiving critique**, or **questioning governing assumptions**.

# When to use which

| Need | Use | Signal |
|------|-----|--------|
| Compare what you expected vs what happened | [Feedback Analysis](/models/learn/feedback-analysis.md) | You made a forecast; reality differed |
| Process praise/criticism without derailing | [Critique Model](/models/learn/critique-model.md) | Live feedback from others |
| Fix the rule that produced the error | [Double-Loop Learning](/models/learn/double-loop-learning.md) | Same class of mistake repeats; tactics already tried |

# Suggested sequences

1. **Missed prediction** → Feedback Analysis → Double-Loop if the *frame* was wrong.  
2. **Harsh review** → Critique Model → Feedback Analysis on your own next prediction.  
3. **Team failure** → Double-Loop (assumptions) + [Swiss Cheese](/models/uncertainty/swiss-cheese-model.md) for layers.
