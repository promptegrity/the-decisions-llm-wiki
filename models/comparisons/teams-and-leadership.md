# Overview

Team problems look the same from the outside (missed goals, friction). Diagnose **composition**, **roles**, **stage**, or **style** before applying tools.

# When to use which

| Question | Use | Not when… |
|----------|-----|-----------|
| Is this group viable (skills, motivation, chemistry)? | [Team Model](/models/collaborate/team-model.md) | Stage is the only issue and membership is fixed |
| Who covers which team roles? | [Roles Model](/models/collaborate/roles-model.md) | Pure interpersonal conflict → [Conflict Resolution](/models/relate/conflict-resolution-model.md) |
| What stage are we in (forming→performing)? | [Team Performance](/models/collaborate/team-performance-model.md) | Composition is broken — fix Team Model first |
| How directive vs participative should I be? | [Management Styles](/models/collaborate/management-styles.md) | You need early wins more than style theory |
| How do we stack visible wins? | [Result Optimization](/models/collaborate/result-optimization-model.md) | Structural incentive trap → [Prisoner's Dilemma](/models/relate/prisoners-dilemma.md) |

# Suggested sequences

1. **New crew** → Team Performance (stage) → Team Model / Roles → Management Styles matched to stage.  
2. **Chronic under-delivery** → Team Model → Roles → Result Optimization.  
3. **Storming** → Team Performance (normalize) → Conflict Resolution if dyadic → Management Styles.  
4. **Leaders over-controlling** → Management Styles + stage check.
