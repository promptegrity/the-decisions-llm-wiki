# Overview

Self-knowledge models answer different questions: **energy**, **visibility to others**, **inner conflict**, **thinking traps**, **life balance**, **time**, **career fit**, **story**, **expectations**.

# When to use which

| Question | Use |
|----------|-----|
| What activities make me absorbed? | [Flow State](/models/understand-self/flow-state.md) |
| What do others see that I don’t? | [Johari Window](/models/understand-self/johari-window.md) |
| Why do I act against what I know? | [Cognitive Dissonance](/models/understand-self/cognitive-dissonance.md) |
| What thinking trap is driving this judgment? | [Cognitive Distortion](/models/understand-self/cognitive-distortion.md) |
| What do I treat as unprovable truth? | [Unthinkable Model](/models/understand-self/unthinkable-model.md) |
| How is life balanced across dimensions? | [Uffe Elbæk Radar](/models/understand-self/uffe-elbaek-radar.md) |
| Am I stuck in past or future? | [Past–Present–Future](/models/understand-self/past-present-future.md) |
| Is this role still a growth fit? | [Personal Performance](/models/understand-self/personal-performance-model.md) |
| What past should design the future? | [Making-Of](/models/understand-self/making-of-model.md) |
| Am I trapped by “potential” expectations? | [Potential Trap](/models/understand-self/potential-trap.md) |

# Suggested sequences

1. **Career unrest** → Personal Performance → Flow → Making-Of.  
2. **Stuck decision + self-doubt** → Cognitive Distortion → [Hard Choice](/models/choose/hard-choice-paradox.md).  
3. **Feedback shock** → Johari + [Critique](/models/learn/critique-model.md).  
4. **Life redesign** → Uffe Elbæk Radar → Past–Present–Future → Potential Trap.
